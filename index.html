QueryScope

Multi-Tenant Database Performance Monitor | .NET 10 & Angular 21

Multi-Tenant Query Performance Tracking & Isolation

Enterprise database clients require detailed monitoring of query bottlenecks, slow transactions, and deadlocks across multiple environments. However, doing so synchronously on a shared platform introduced high risk of cross-tenant data exposure and caused thread-pool starvation under high load.

Additionally, parsing execution plans and resolving XML deadlock graphs in real-time placed heavy strain on the primary API, leading to latency spikes for concurrent end-users.

Key Challenges
  • Risk of cross-tenant database metric leakage in a shared system.
  • Latency spikes during synchronous processing of heavy XML deadlock graphs.
  • Main API blocking during continuous query metric collection.

Architectural Solution

Designed a secure, decoupled multi-tenant monitoring pipeline based on .NET 10 and Angular 21.

  • Secured tenant data using EF Core Global Query Filters.
  • Offloaded query collection to an asynchronous background worker service.
  • Created an Angular 21 HTTP Interceptor for automatic tenant context mapping.
  • Visualized complex deadlock process trees on an interactive frontend.

protected override void OnModelCreating(ModelBuilder builder)
{
    base.OnModelCreating(builder);

    // Apply tenant-level filter automatically
    builder.Entity<CollectedQuery>()
        .HasQueryFilter(q => q.TenantId == _tenantProvider.TenantId);

    builder.Entity<DeadlockEvent>()
        .HasQueryFilter(d => d.TenantId == _tenantProvider.TenantId);
}
tenant-header.interceptor.ts
export const tenantInterceptor: HttpInterceptorFn = (req, next) => {
  const tenantService = inject(TenantContextService);
  const tenantId = tenantService.getCurrentTenantId();

  if (tenantId) {
    const cloneReq = req.clone({
      headers: req.headers.set('X-Tenant-Id', tenantId)
    });
    return next(cloneReq);
  }
  return next(req);
};

C# Micro-ORM Read Repository Implementation

Demonstrating typical high-speed async query pattern utilizing Dapper connection mapping and SQL parameterization to prevent deadlocks.

RepairRepository.cs
public class RepairRepository : IRepairRepository
{
    private readonly IDbConnectionFactory _connectionFactory;

    public RepairRepository(IDbConnectionFactory connectionFactory)
    {
        _connectionFactory = connectionFactory;
    }

    public async Task<IEnumerable<RepairDetailDto>> GetRepairsWithDetailsAsync(int statusId)
    {
        // High-performance query bypassing full Entity Graph mapping for read views
        const string sql = @"
            SELECT r.Id, r.DefectDescription, r.CreatedDate, 
                   s.StatusName, p.PartNumber
            FROM dbo.Repairs r WITH (NOLOCK)
            INNER JOIN dbo.Statuses s ON r.StatusId = s.Id
            LEFT JOIN dbo.RepairParts p ON r.Id = p.RepairId
            WHERE r.StatusId = @StatusId;";

        using var connection = _connectionFactory.CreateConnection();
        
        return await connection.QueryAsync<RepairDetailDto>(sql, new { StatusId = statusId });
    }
}

Asynchronous Message Publisher for Azure Service Bus

C# code structure demonstrating thread-safe asynchronous dispatch billing event posting.

ServiceBusPublisher.cs
public class ServiceBusPublisher : IMessagePublisher
{
    private readonly ServiceBusSender _sender;

    public ServiceBusPublisher(ServiceBusClient client, string queueName)
    {
        _sender = client.CreateSender(queueName);
    }

    public async Task PublishPaymentRequestAsync(PaymentRequestMessage message)
    {
        var jsonString = JsonSerializer.Serialize(message);
        var serviceBusMessage = new ServiceBusMessage(Encoding.UTF8.GetBytes(jsonString))
        {
            ContentType = "application/json",
            MessageId = message.TransactionId.ToString()
        };

        // Ensures thread-safe async scheduling outside web thread pool
        await _sender.SendMessageAsync(serviceBusMessage);
    }
}

Thread-Safe SQLite Write Cache Implementation

Xamarin framework C# structure ensuring thread-safe barcode scans persist locally to prevent data loss.

OfflineScanCache.cs
public class OfflineScanCache : IOfflineScanCache
{
    private readonly SQLiteAsyncConnection _db;
    private readonly SemaphoreSlim _semaphore = new SemaphoreSlim(1, 1);

    public OfflineScanCache(string dbPath)
    {
        _db = new SQLiteAsyncConnection(dbPath);
        _db.CreateTableAsync<BarcodeScanEntity>().Wait();
    }

    public async Task<int> SaveScanToCacheAsync(BarcodeScanEntity scan)
    {
        await _semaphore.WaitAsync();
        try
        {
            // Ensures thread-safe write isolation during background uploads
            return await _db.InsertAsync(scan);
        }
        finally
        {
            _semaphore.Release();
        }
    }
}
